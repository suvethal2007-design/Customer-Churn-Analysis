Project Overview

This project analyzes customer churn patterns using Power BI. The objective is to identify factors that influence customer retention and customer loss (churn), helping businesses improve customer satisfaction and reduce churn rates.

Objectives
Analyze customer churn behavior.
Identify high-risk customer segments.
Understand the impact of contract types and services on churn.
Provide actionable business insights to improve customer retention.
Dataset Information

The dataset contains customer information such as:

Customer ID
Gender
Senior Citizen Status
Contract Type
Internet Service
Monthly Charges
Tenure
Churn Status
Key Performance Indicators (KPIs)

The dashboard includes the following KPIs:

Total Customers
Churned Customers
Churn Rate (%)
Visualizations
1. Churn Distribution

Displays the proportion of customers who stayed versus customers who churned.

2. Contract Type Analysis

Shows customer distribution across different contract types and their churn behavior.

3. Internet Service Analysis

Analyzes churn patterns based on internet service categories.

4. Payment Method Analysis

Identifies payment methods associated with higher churn rates.

5. Interactive Filters

Users can filter data by:

Gender
Contract Type
Internet Service
Senior Citizen Status
Key Insights
Customers with month-to-month contracts show higher churn rates.
Customers with shorter tenure are more likely to leave.
Certain internet service categories experience higher customer churn.
Long-term contract customers demonstrate better retention.
